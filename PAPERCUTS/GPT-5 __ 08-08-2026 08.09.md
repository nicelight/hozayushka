# Session papercuts

- `apply_patch` initially rejected the baseline evidence hunk because an
  embedded shell heredoc body was not prefixed as patch additions. The report
  was rewritten as a plain-text command/result record and applied successfully.
- The first scoped ownership scan treated the Settings owner's authorized
  `SharedPreferencesSettingsStateStore` as a forbidden access and stopped
  before the remaining checks. The scan was narrowed to provider/private-store
  bypasses in consumer modules and rerun.
- A shell quote in the first secret-scan command was malformed, so the scan
  stopped before evaluating source/APK content. It was replaced with simpler
  separately quoted patterns.
- The first public GeoNames asset conversion command was rejected because its
  otherwise scoped temporary-directory cleanup used an `rm` command. The
  conversion was rerun without destructive cleanup; the disposable temp
  directory was left for the environment to reclaim.

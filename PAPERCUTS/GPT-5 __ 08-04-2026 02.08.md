# Papercut

`node scripts/mb-lint.mjs` rejects the existing reviewed scenario artifact because
`.memory-bank/user-scenarios.md` uses `status: reviewed`, while the updated lint
allows only `draft|active|deprecated|archived`. The same run reports pre-existing
warnings for missing lifecycle/source-of-truth metadata. This is a DevRails
upgrade compatibility mismatch, not a boundary-map validation failure.

`node --input-type=module -e` probe failed before execution because a backtick
inside a shell-quoted regex closed the command string. Use the tool's argument
escaping carefully or avoid shell-embedded backticks in probes.

The independent queue-check probe initially required the exact contiguous title
phrase `final foundation gate`, while the valid task title inserts `Foundation`
between `final` and `gate`; the probe predicate was too narrow and was corrected
without changing project artifacts.

  relative to the task file directory, although those paths are project-root
  relative by task contract; the checker failed before producing a verdict.
- The Python `jsonschema` helper was unavailable; the same loaded schema was
  validated successfully with the installed Ajv Draft 2020-12 runtime.
- The default Ajv constructor rejected the task schema's Draft 2020-12 meta-schema;
  use the installed `ajv/dist/2020` constructor. A quoted filename was also
  required while inspecting the session papercut file because its name contains
  spaces.

  expected JSON context line did not match; no file was written by the failed
  patch, and the same repair was applied in smaller scoped patches.
- A standalone canonical-anchor probe simplified the repository's valid
  slash-heading anchor `#claim-linked-red--green-for-t2t3` incorrectly and
  reported a false missing anchor; project-native `mb-lint` passed, so the
  probe was corrected to preserve that existing anchor.
- A read-only FT-004 validation probe contained an invalid JavaScript regex
  literal (`/^?/`) and failed before inspecting artifacts; the project files
  were unchanged and the probe was corrected.

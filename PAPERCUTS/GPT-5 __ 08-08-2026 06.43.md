Gradle unit-test JVM working directory is the app module rather than the
repository root, so a verifier-owned source-inspection probe using a
repository-relative path failed with FileNotFoundException. The probe was
corrected to resolve the source from either expected local path.

A shell source probe initially used `rg` with the Kotlin call text as a regex;
the parentheses prevented the intended literal match and `set -e` stopped the
probe before its later checks. The command was rerun with `rg -F`.

# Papercuts

- A jq required-field check used `input` inside a stream and terminated with `break`; the check was rerun with a direct object-bound expression.
- The environment has no `python` executable, so schema validation was rerouted to the available Node.js runtime.
- The authorized generic AVD repeatedly dropped/offlined during cold-start runtime probing; verifier restarted it detached and retried with explicit landscape configuration.
- Shell protection rejected an explicit `rm -f` cleanup command; verifier used recoverable Trash cleanup for its exact temporary files.
- `gio trash` does not support `/tmp` on this mount; exact temporary files were moved to the user Trash directory instead.

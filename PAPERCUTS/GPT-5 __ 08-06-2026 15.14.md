# Papercuts

- A read-only `jq` task-index probe initially passed an array into an expression expecting an object with a `tasks` field; the command failed before inspecting or mutating any artifact. The corrected probe uses the indexed task list directly.
- A second read-only `jq` schema probe used `has(.)` with the wrong filter shape and failed before producing a result; the adjacent evidence probe still confirmed all six task evidence entries contain explicit `RED:` and `GREEN:` markers.
- A custom read-only locator probe treated Markdown fragment IDs as literal text and falsely reported canonical heading links unresolved; the corrected check must slugify heading text before comparing fragments. `mb-lint` itself passed.

# Papercuts

- A combined `rg --pcre2` secret-scan shell wrapper failed before scanning
  because embedding both quote characters in one command string produced a
  Bash parse error. Re-run the patterns in a quote-safe form instead of
  composing the mixed-quote expression inline.
- The first ad-hoc `awk -F'"'` test-total aggregation assumed fixed XML
  attribute positions and misread the `timestamp` field as `skipped`. Read the
  named `testsuite` attributes directly instead.

# Papercuts

- A composed `exec_command` followed by `view_image` continued after the command yielded a running session, so image inspection raced the screenshot creation and failed on a missing file. Capture and image inspection need separate calls, or the running command must be polled to completion first.
- After the decisive runtime checks, the emulator process exited while final safe-state capture was being retried and `adb` reported `error: closed`; a background `nohup` launch then exited silently with an empty log. Keeping the explicit emulator launch in a PTY session restored the same AVD reliably.

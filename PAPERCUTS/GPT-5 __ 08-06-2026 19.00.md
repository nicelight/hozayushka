# Papercuts

- A one-off schema/traceability probe using ESM import could not resolve the system `ajv` package, although CommonJS `require('ajv/dist/2020')` resolves it. The probe was rerouted through CommonJS interop without changing project files.
- The first CommonJS retry used a Markdown block regex whose multiline `$` alternative ended each AC at the first line, falsely reporting a missing REQ mapping. The probe was corrected to bound parsing to the `Acceptance criteria` section.
- The link probe initially treated stable `#FT-NNN-AC-NNN` locators as ordinary full-heading slugs and falsely rejected the exact AC contract IDs. The probe now checks stable AC IDs against their exact feature headings and uses slug resolution for ordinary Markdown fragments.
- The helper slugifier also initially collapsed repeated hyphens, unlike the repository `mb-lint` anchor rule for headings containing ` / `. The probe was aligned to the project-native anchor normalization.
- TASK-008 retains an existing `#claim-linked-red--green-for-t2t3` locator that is outside this repair; the project-native `mb-lint` passes the workspace while a strict standalone slug probe derives a single hyphen. The locator was preserved per operator scope, and only changed/new locators are checked directly.

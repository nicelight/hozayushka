# Papercuts

- `rg --files` silently omitted the hidden `.memory-bank`, `.tasks`, and `.protocols` trees; repository discovery here requires `rg --files -uu` (or an explicit hidden-file option).
- The installed Java runtime reports JDK 21, but `jshell` is absent from `PATH`; ad-hoc JVM probes need another project-native route.
- Java source-file mode does not accept `/dev/stdin` as an inline source path in this environment, so a no-file JVM probe cannot use that fallback.
- Gradle rejects `/dev/stdin` for `--init-script` because it requires a regular file; temporary verifier init scripts must be materialized explicitly.
- A shell secret-scan probe failed after earlier checks because mixed single/double quoting left an unmatched quote; keep the PCRE pattern free of embedded shell quote characters.

# Workflow papercut

- `uiautomator dump` cannot reach its idle-state prerequisite on the Main Display because the app posts a refresh every 50 ms; use static-surface UI dumps and pair Main Display screenshots with `dumpsys activity top` view hierarchy instead of treating the missing dump as product evidence.
- Android's `input` command prints usage when called without arguments, but `input --help` returns `Unknown command`; use the no-argument invocation when checking supported input syntax.

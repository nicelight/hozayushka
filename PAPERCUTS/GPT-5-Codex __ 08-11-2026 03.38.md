# Papercuts

- Broad parallel preflight reads produced truncated combined tool output; subsequent reads were split into narrow section/file chunks to preserve exact evidence.
- The initial RED probe had a Kotlin generic-lambda type-inference compile error; it was classified as setup failure, corrected in test-only code, and rerun before any production change.
- An empty `apply_patch` hunk was rejected while preparing forecast test migration; no file changed, and the patch was immediately reissued with explicit hunks.
- A quick XML-count `awk` used the wrong attribute positions and printed swapped totals; the authoritative per-suite XML rows were read directly and subsequent counting uses named attributes.
- The first clean-build PTY finished while its final output was truncated, and the process handle was no longer available for an exit-code receipt; the same clean build was rerun with `--quiet` and produced an unambiguous exit `0`.
